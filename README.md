# 📊 SaaS Retention & Revenue Engine (SQL + IA + Excel)

## 📌 Visão Geral do Projeto
Este projeto foi desenvolvido para resolver um problema crítico em empresas de modelo de assinatura (SaaS): **a previsão e prevenção do cancelamento de clientes (Churn)**.

A solução integra todo o ciclo de dados, desde a extração e tratamento em **SQL**, passando pelo processamento preditivo/prescritivo via **Inteligência Artificial (Python)**, até a entrega de um **Dashboard Executivo interativo no Excel**.
